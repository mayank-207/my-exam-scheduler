# My Exam Scheduler

A lightweight, browser‑based exam schedule planner built with React and
TypeScript --- no backend required.\
Users can create, manage and follow a structured preparation plan based
on available time and subject difficulty.

------------------------------------------------------------------------

## 🔎 Overview

My Exam Scheduler helps you organize exam prep efficiently by letting
you schedule study sessions, track subjects and priorities, and stay on
top of your workload --- all via your browser, stored locally.

------------------------------------------------------------------------

## 🛠️ Tech Stack & Tools

-   **Frontend:** React + TypeScript\
-   **Styling:** Tailwind CSS\
-   **State / Data persistence:** localStorage (no backend or external
    DB)\
-   **Build tool:** Vite\
-   **Languages:** TypeScript / JavaScript / HTML / CSS

------------------------------------------------------------------------

## 🚀 Getting Started

### Installation

``` bash
npm install
```

### Development

``` bash
npm run dev
```

### Production Build

``` bash
npm run build
```

------------------------------------------------------------------------

## 🧑‍💻 Usage

-   Launch the app in your browser.\
-   Add subjects or exams with details like name, difficulty, and
    available study time.\
-   Organize your study plan and track progress --- everything is saved
    locally in the browser.\
-   Works offline with persisted data in localStorage.

------------------------------------------------------------------------

## 🎯 Key Features

-   Subject / exam management --- add, edit, remove entries.\
-   Planning based on user-defined time and difficulty.\
-   Lightweight --- no backend or external dependencies.\
-   Persistent data stored in browser --- sessions remain even after
    closing the tab.
